個人サイトに必要な動的処理は、驚くほど少ない。

感想レターの受付、レート制限、たまに画像。それ以外はビルド時に固めてしまってよい。Astro の Content Collections で型を付け、Cloudflare Workers で端だけを生かす。

```ts
// イメージ: レターは定型スタンプのみ受け付ける
type Letter = { postId: string; stamp: string; createdAt: string };
```

## なぜ TanStack か

Router と Query は、将来の小さなアプリ面（検索、メモ同期、管理）に伸びしろがある。いまは Reading Rail などの島として置き、コンテンツ配信の経路を汚さない。

速さはおしゃんの一部だ。だが速さだけで人は好きにならない。静かさと、見つけたときの嬉しさが残るかどうか——そこを測る。
